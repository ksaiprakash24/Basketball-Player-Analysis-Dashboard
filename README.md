# Basketball-Analytics-Dashboard

## 🏀 Basketball Player Performance Analytics Dashboard (Power BI)

### 1. Project Title / Headline

🏀 Basketball Player Performance Analytics: Scoring Trends & Player Insights Dashboard
An interactive Power BI dashboard designed to analyze player performance, scoring trends, efficiency metrics, and contribution analysis.

---

### 2. Short Description / Purpose

The Basketball Player Performance Dashboard is a data analytics solution that provides insights into player statistics, scoring patterns, and efficiency metrics across multiple seasons. It helps analysts identify top performers and evaluate player contributions.

---

### 3. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 **Power BI Desktop** – Dashboard creation and reporting
* 📂 **Power Query** – Data transformation and cleaning
* 🧠 **DAX (Data Analysis Expressions)** – KPI creation and advanced calculations
* 🧩 **Data Modeling** – Structured relationships across datasets
* 📁 **File Format** – `.pbix` and `.png`

---

### 4. Data Source

Source: Basketball dataset (player-level and season-level data)

The dataset includes:

• Player statistics (points, assists, rebounds)
• Season-wise performance data
• Player efficiency metrics
• Shooting percentages
• Player rankings

---

#### 5. Features / Highlights

• Business Problem

Sports analysts often struggle to evaluate player performance due to scattered and unstructured data. Questions like:

Who are the top-performing players?
How does scoring trend across seasons?
What contributes most to player performance?
How efficient are players over time?

are difficult to analyze without proper dashboards.

• Goal of the Dashboard

The dashboard aims to:

• Analyze player performance across seasons
• Identify top scorers and contributors
• Track scoring and efficiency trends
• Provide interactive and visual insights

---

### 7. Business Impact & Insights

• **Performance Tracking:** Identify top-performing players
• **Trend Analysis:** Understand scoring growth over time
